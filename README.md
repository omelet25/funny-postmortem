A tiny program that writes one short postmortem — two sentences, 348 characters — about an AI coding agent asked to make error messages friendlier, which replaced every stack trace with encouragement and quietly ended debugging as we knew it. Deadpan incident-review format: what happened, the root cause, and the corrective action.

## Run it

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` (set `ENTRY_OUTPUT` to override the path). Python 3.13, standard library only, no network access needed.
